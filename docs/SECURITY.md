# 安全说明

## 现状防护

1. **仅回环监听**：HTTP API 绑定 `127.0.0.1:8765`，不暴露到局域网/WAN。
2. **随机 token 鉴权**：每次全新安装生成 64-bit 随机 token（App 启动时生成并
   持久化在 SharedPreferences，进程重启不变）。所有 `/api/*` 请求必须携带
   `X-Api-Token` 头或 `?token=` 参数。
3. **内置 Web 控制台同样需 token**（页面内嵌，仅本机可读）。
4. **无外部网络行为**：App 不向任何远程服务器上报数据；仅 WebView 网页本身
   的网络行为（访问用户浏览的站点）。

## 已知边界（请在可信设备上使用）

- **同设备其他 App 可达 localhost**：Android 应用沙箱内，其他 App 可以访问
  `127.0.0.1:8765`。token 随机且不易泄露，但这是本地服务固有权衡。
  请勿在安装有恶意 App 的设备上长期运行。
- **token 仅在本地**：token 不会出现在任何远程请求中，除非你把它复制出来
  （例如在 App「信息」面板查看）。
- **浏览器权限即 API 权限**：能调用 API 即等同于获得该浏览器完整控制权
  （可访问登录态 Cookie、可执行任意 JS）。VPN/代理环境下谨慎使用。

## 加固建议（可选）

- 使用后退出 App（进程退出服务即停止，下次唤醒重新监听）
- 系统设置中不授予「定位」「无障碍」等无关权限
- 定期在「缓存管理」中清除 Cookie/数据
